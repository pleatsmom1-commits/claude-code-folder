# 정산서 일괄처리 매크로

정산청구서(.xlsm)에 추가해서 쓰는 VBA 모듈입니다. 기존 `정산서조회` 매크로를 그대로 재사용합니다.

## 설치 (한 번만)

1. 정산청구서 .xlsm 파일을 엽니다. (작업 전에 복사본을 하나 만들어 두세요.)
2. `Alt + F11` → 메뉴 **파일 → 파일 가져오기** → `정산서일괄처리.bas` 선택
   (파일은 한글 Windows용 CP949 인코딩이라 한글이 깨지지 않습니다.)
3. 저장 후 닫기. 필요하면 정산서 시트에 도형을 넣고 **매크로 지정**으로 버튼을 만드세요.

## 사용법

| 매크로 | 하는 일 |
|---|---|
| `정산서_이미지_일괄저장` | 정산일을 입력하면 그날 정산서DB에 있는 모든 업체의 정산서를 `정산서이미지\yyyymmdd\yyyymmdd_상호.png` 파일로 저장합니다. 끝나면 폴더가 열립니다. |
| `정산서_순차복사` | 업체별 정산서를 한 장씩 클립보드에 그림으로 복사합니다. 카톡방에서 `Ctrl+V` → `Enter` 후 엑셀의 [확인]을 누르면 다음 업체로 넘어갑니다. 중간에 멈췄다면 시작 업체 이름을 입력해 그 업체부터 이어서 할 수 있습니다. |

- 순서는 정산서DB 시트에서 해당 정산일 행이 나오는 순서 그대로입니다(예: 2026-10-08 → 라미다이아부터 핸섬보이까지 64곳).
- 캡처 범위는 정산서_결과 시트의 B열~I열, "상호(입금자명)" 윗줄부터 "*보조설명" 두 줄 위까지입니다(지금 드래그해서 복사하던 부분).
- 저장 폴더는 정산청구서 파일과 같은 폴더 아래에 생깁니다.
