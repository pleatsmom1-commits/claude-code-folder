# 정산서 발송 기능 미리보기 확인 순서

미리보기 사이트 맨 위에 **빨간 띠**가 보이면 실제 DB에 연결된 상태입니다.
아래 순서 중 ⚠️ 표시는 실제 DB에 저장되는 동작입니다.

## 0. 준비 (처음 한 번)
- Supabase SQL Editor에서 `supabase/settlement.sql` 실행 (새 표만 추가, 기존 데이터에는 영향 없음)

## 1. 기존 기능이 그대로인지
- [ ] 관리자 로그인 → [주문 관리] 탭에 주문 목록이 평소처럼 보임
- [ ] [셀러 관리] 탭이 평소처럼 보임

## 2. 정산 거래처 연락처
- [ ] [정산서 발송] 탭 → 아래쪽 [연락처 엑셀 올리기] ⚠️ → 정리한 연락처 엑셀 선택
- [ ] "OO곳 등록 완료" 후 표에 상호·연락처가 보임, 검색이 됨

## 3. 정산서
- [ ] [정산청구서 엑셀 선택] → 정산청구서(.xlsm) 선택 → 몇 초 뒤 마지막 정산일 업체 목록이 나옴
- [ ] 순서·청구금액이 엑셀 정산서와 같은지 2~3곳 비교
- [ ] [미리보기]로 정산서 화면 확인 (저장 전)
- [ ] [정산서 저장 (링크 만들기)] ⚠️ → 상태가 "링크 생성됨"
- [ ] [보기] → 휴대폰에서도 열어보기 / [링크 복사] → 카톡 '나와의 채팅'에 붙여서 눌러보기

문제가 없으면 "합쳐줘"라고 알려주세요.
